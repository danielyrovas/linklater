<p><i>LinkLater</i> is an unofficial Android client for <a href='https://github.com/sissbruecker/linkding' target='_blank' rel='nofollow noopener'>LinkDing</a>, a self-hosted bookmark manager that is designed be to be minimal, fast, and easy to set up using Docker..</p><p><br><b>Features:</b></p><ul><li>Save bookmarks through the Android share menu.</li><li>Easily add tags to bookmarks.</li><li>View recent bookmarks.</li></ul>
